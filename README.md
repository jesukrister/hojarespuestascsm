# Lector de Hojas → CorrigeYa

Este repositorio era el **Lector de Hojas de Respuesta**. El proyecto ahora es **CorrigeYa**:

- Página: <https://corrigeya.cl>
- Código: [corrigeya/app](https://github.com/corrigeya/app) (todo el historial está ahí).

Aquí queda sólo la página de la **dirección antigua** (`jesukrister.github.io/hojarespuestascsm/`),
como `index.html` y `404.html`:

- quien abre un enlace antiguo sin datos guardados pasa a la página equivalente de corrigeya.cl;
- quien tiene datos guardados en este navegador ve «CorrigeYa se mudó» y el botón para llevarlos
  (corrigeya.cl/traer.html la abre y recibe los datos, sólo en ese navegador).

No borres ni renombres este repositorio: es la dirección antigua. La fuente de esta página es
`mudanza/index.html` en corrigeya/app.
